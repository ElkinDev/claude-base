# radar-profile.txt: the weighted search profile of radar-discover.py, an example to edit.
#
# Format: one term per line, "<weight> <term>". The weight is a number from 1 to 5 (5 = most useful
# to you); the term is everything after the first run of spaces, so a phrase needs no quotes.
# Lines that start with # and blank lines are ignored; a malformed line is reported and skipped.
#
# How a term is used:
# - GitHub search: terms are grouped five to a query, joined with OR, in file order, and searched in
#   repository name, description and topics (GitHub's default), once for repositories created in the
#   last 30 days and once for repositories pushed in the last 7 days with more than 300 stars.
# - Relevance: each term is matched, case-insensitive, in the description, the topics and the first
#   4000 characters of the README; "-", "_", "." and spaces inside a term match each other, so
#   "claude-code" also matches "Claude Code". Relevance is the sum of the matched weights, capped at 12.
#
