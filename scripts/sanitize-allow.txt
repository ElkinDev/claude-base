# Sanctioned placeholders and known-good names. One entry per line: a literal, or a Python
# regex behind a `regex:` prefix. Lines starting with `#` are comments.
#
# An entry clears a finding only when it full-matches the name that rule captured: the user in a
# home path, the domain in an address, the org in a forge or tracker URL. Nothing else on the
# line is consulted, so an entry can neither clear an unrelated leak that shares the line nor
# clear a longer value that merely starts with it: `you` does not clear `you-know-who`, and
# `example.com` does not clear `example.com.attacker.io`. Matching is case-insensitive.
#
# A rule that captures no name, which is every credential shape, can never be cleared here.

# The user names the kit writes instead of a real one.
you
user
username
yourname
your-name
%USERNAME%
$USER
